# 安装旅行壁纸

## 给第一次使用 DSH 的朋友

安装包是 `dsh-planet-news-0.14.1.tgz`。它可以在市场收录前直接安装，不需要能访问作者的私有 GitHub 仓库。源码 ZIP 用于查看／开发，不是给新手的安装包。

1. 安装并打开 DeepSeek Harness。项目本机环境为 Windows 11、DSH 桌面 0.2.2-rc.1；其他版本待验证。
2. 将作者发来的 `.tgz` 保存到你自己的电脑，并复制文件的完整路径，不要照抄作者电脑的路径。
3. 在 DSH 的插件安装入口填本地包绝对路径；或把路径交给有插件安装能力的 DSH 对话，让它核对包名 `dsh-planet-news`，安装到当前使用的配置。
4. 按 DSH 显示的来源、依赖与安装确认提示操作。首次安装可能需要联网获取依赖。
5. 在 DSH 设置中打开旅行壁纸，配置自己的文字和生图通道，再手动生成第一张。

可以直接发给 DSH：

> 请安装我提供的旅行壁纸本地 tgz 包，先检查包内名称是 dsh-planet-news。安装到我现在使用的 DSH 配置，保留已有插件设置和旅行图库。不要自动生成图片或播放声音。文件完整路径是：请替换成我电脑上的实际路径。若无法安装，说明具体原因，不要凭插件名称去安装同名未知项目。

仅说“安装旅行壁纸玩玩”不够：尚未收录市场时，DSH 不一定知道从哪里取得安装包。作者私有仓库的链接也不能直接给没有访问权限的人使用。

## 终端备用方式

已配置 `dsh` 命令的用户可使用：

```powershell
dsh plugin --profile <当前配置名> add "<本机tgz的完整绝对路径>"
```

将两处尖括号内容替换为实际值。配置名不是固定的 `web` 或 `desktop`，要与当前使用的 DSH 配置一致。没有 `dsh` 命令时，优先使用应用中的插件管理／安装能力，不必为了试用先学习终端。

安装包依赖 `sharp`；首次安装不等于完全离线安装。请按安装器要求处理本机依赖，不要为了绕过安装错误盲目禁用所有检查。

本地 `.tgz` 与绝对路径的接受方式依据 [DSH 插件安装 spec 实现](https://github.com/deepseek-ai/deepseek-harness/blob/master/packages/boot/plugin-manager/src/install-spec.ts)，CLI 格式依据 [官方兼容性指南](https://github.com/deepseek-ai/deepseek-harness/blob/master/docs/upgrade-guide/v0.2.1-alpha.3/plugin-engines-dsh/guide.zh.md)。这不代表已在每位朋友电脑上试装成功。

## 升级和卸载

升级时先记录当前版本并备份旅行数据目录 `~/.dsh/planet-news/`，再安装作者提供的新包。不要删除整个 `.dsh` 目录；那里可能包含其他插件、账号与个人设置。

当前未把卸载／重装后的完整数据保留体验声明为已验证。试装时请使用无重要资料的新配置，或先备份，再验证恢复。

## 如果找不到旅行壁纸设置

先检查插件是否安装到正在使用的配置，是否启用，以及 DSH 是否提示加载错误。将插件版本、DSH 版本和经过遮挡的错误截图发给作者。不要将个人 API 密钥或登录凭据一起发出。
