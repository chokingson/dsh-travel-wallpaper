# 怎么安装旅行壁纸

## 四步开始

1. 下载并打开 **DeepSeek Harness（DSH）**，登录、配置模型账户。
2. 下载 **旅行壁纸安装包**，文件名为 `旅行壁纸-0.14.1.tgz`。不用下载源码，也不用手动解压。
3. 新建聊天，点加号，把安装包作为附件交给 DSH，告诉它：

   > 帮我安装这个旅行壁纸插件，装好后告诉我怎么用。

4. 安装完成后，在 **DSH 设置 → 旅行壁纸** 中配置生图渠道，选择角色、世界和画风，点击 **制作今日壁纸**。

只要一个安装包，不用上传一堆项目文件。无需安装 Wallpaper Engine 也能使用 Windows 静态壁纸；多图轮播才需要它。

## 上传不了附件，或者 AI 没装好？

附件入口是否接受 `.tgz`，还需要在实际使用的 DSH 版本中确认。不能仅凭附件发出，就判断插件已安装。

如果附件入口不接受安装包，把文件保存到本机，告诉 DSH 文件放在哪里，请它用本地插件安装方式处理。或者在 DSH 的插件安装入口选择本地安装包。仍无法安装时，把错误截图发给作者，不需要自己研究包名或终端命令。

安装时如遇到确认提示，核对安装包来自作者后按 DSH 提示操作。第一次安装可能需要联网下载依赖。

## 账户与费用

插件本身免费。提示词整理需要可用的文字模型，生图需要自己的订阅、API 额度或本地环境。文字额度不一定能用于生图，赠送额度以账户实际显示为准。

本机已核对的环境为 Windows 11、DSH 桌面版 0.2.2-rc.1；其他版本兼容范围仍待验证。
