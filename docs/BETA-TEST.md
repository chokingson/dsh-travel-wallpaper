# 给朋友的试装说明

旅行壁纸是一个免费 DSH 插件，带角色或自己的赛博分身去不同世界，生成桌面壁纸、世界见闻和角色来信。也可以不带角色，只观察世界。

这次是候选版试装，不需要等市场收录。作者将直接提供 `.tgz` 插件包；安装方法见 [INSTALL.md](INSTALL.md)。包是程序，不要把它当图片或源码 ZIP。

## 试装顺序

1. 记录 DSH 与 Windows 版本，从本地 `.tgz` 安装并找到设置。
2. 看能否识别已有订阅，或在渠道设置中完成登录／填写自己的 API；不愿消耗额度时停在这里即可。
3. 经本人同意使用额度后，先用 Windows 静态壁纸、单张、默认尺寸，按自己的需求生成一张。
4. 尝试角色／观察世界、参考图开关、悬浮预览与导出。不要在没有备份的情况下测试删除数据。
5. 愿意做进阶测试时，再验证定时、回信／干涉世界、卸载重装及多显示器；先说明这些操作会影响什么。

作者承诺在明确启动本轮测试前，不通过此说明自动操作任何朋友电脑，不付款、不代用其生图额度。
