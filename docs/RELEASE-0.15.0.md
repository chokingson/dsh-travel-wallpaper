# 旅行壁纸 0.15.0

任务1—9统一整合版。此记录随实际检查继续更新，不将未进行的检查写为通过。

## 已实现

- 每日默认中国时间06:00；保留用户已设时间。DSH恢复运行后补执行，3分钟间隔、最多3次重试。每日、手动、预约和剧情任务独立记录；复用已提交的远端任务和缓存成图，取消不封锁下一天。
- 合并已完成任务2/3/4：文生图与图生图两套规范、20种短画风、已审50个世界事实，以及壁纸、见闻、来信共享的已提交剧情。
- 今日/次日剧情：竖排A/B/C与一行自定义互斥，先选中高亮，再点继续。今日根据实际剧情生成三种后续，不附固定正反结局；次日后台保留完整探索/停留/意外规则。全文、日期、实际配置时间持久化，冲突不静默覆盖。
- 同行最多三名，顺序决定主角色。每张参考图有独立名称、外观、人设/参考设定和称呼，主角色独自写信；支持有图与纯文字描述混合。观察模式保留设置但清空执行队伍，不注入默认角色或来信。
- 订阅与官方API按各自协议发送多图；未知兼容端点默认一张并明确拒绝超限。具体模型和账户的实际可用性仍以运行结果为准。
- 特产服务独立持久化：预设50世界各一件固定收藏、50张正式图；动态物品实时设计与生图。旁白使用本次已提交事实和队伍快照。50%当前世界、50%其他预设世界，重试不换来源。文字/图片全部完成并存档才入藏。
- “特产”页只展示实际收到的物品，重复经历归在同一物品下；50件进度与紧凑清单按需查看，不做剪影墙。动态图鉴不占50进度。
- 已到访世界新增0/50累计进度；预设随机本轮不放回，集齐50才开启新轮。累计进度不清零，手选仍可重访，不按中文名称合并世界身份。

## 兼容与执行裁定

- 旧任务234按交付manifest逐项核对后合并；旧壁纸、来信与按名称归档的分类仍可读。新作品保存独立成员身份、完整参与队伍和实际出镜成员。
- 角色主次按选择顺序，第一位写信；移除后下一位接任。称呼默认“用户”。
- 同一日期×实际世界/行程×有序队伍最多一件自动送达，多人共享。这是任务书建议的工程默认，集中在specialties.enqueue，之后可调整。
- 次日剧情与同日盲盒预约冲突时明确提示先取消或恢复随机，不静默决定优先级。
- 收藏失败不回滚壁纸。新版本旅行有持久化待入队标记，队列暂不可写后可补建；老用户档案不批量补发历史礼物。
- 内置随机以成功发布且图片存在为准；抽候选不消耗名额，失败/取消不算到访。同一真实世界的旧ID别名兼容，不凭同名合并自定义世界。
